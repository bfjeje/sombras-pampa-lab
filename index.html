¿Qué significan los códigos?

E_NET_TIMEOUT El servidor no respondió antes del límite. Posible Wi‑Fi, IP, puerto o firewall.

E_NET_BLOCKED_OR_UNREACHABLE El navegador no devolvió una respuesta accesible. Puede ser HTTP mixto, permiso de red local, CORS, firewall o servidor apagado: no se puede identificar uno solo desde JavaScript.

E_HTTP_STATUS_* El servidor respondió con ese código HTTP (404, 418, 500…).

E_SERVER_ID_MISMATCH La dirección apunta a otro servidor distinto del emparejado.

E_WS_ERROR WebSocket falló. Puede ser bloqueo del navegador, red o servidor.

E_SW_UNAVAILABLE Service Worker no disponible en este origen o navegador; esperado en HTTP local.

E_IDB_* Problema al abrir, escribir o leer IndexedDB.

E_BROWSER_SECURITY_POLICY El navegador notificó explícitamente un bloqueo de política de seguridad.

E_TEST_EXPECTED_418 Error deliberado provocado para verificar el registro, no una avería.

En la notebook, buscá también servidor/logs/servidor-AAAA-MM-DD.jsonl. Compará el rid de ambos registros. Si la petición no aparece en el servidor, falló antes de llegar a él.
